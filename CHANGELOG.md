# История изменений

## v0.1.0

Первый подготовленный релиз.

### Синхронизация

- Загрузка Obsidian vault в ZIP через Telegram.
- Создание форум-тем по папкам и публикация Markdown-заметок.
- Преобразование `[[wikilinks]]` в ссылки на Telegram-сообщения.
- Обновление изменённых заметок с сохранением ID сообщений.
- Повторное использование известных тем и ручная привязка через `/bindtopic` и `/bindnote`.
- Дерево папок и карта связей в отдельной теме навигации.

### Доступ и запуск

- Обязательный список разрешённых пользователей `ALLOWED_USER_IDS`.
- Проверка ID до обработки команд, архивов и уведомлений о темах.
- Отклонение команд от имени группы или анонимного администратора.
- Polling для локального запуска и webhook для Render.
- Пример `.env` и инструкции для Windows и Linux / macOS.

### Репозиторий

- Тесты в GitHub Actions на Windows и Linux с Python 3.12 и 3.14.
- Создание черновика релиза по тегу версии после успешных тестов.
- Шаблоны Issues, pull request и описание первого релиза.
