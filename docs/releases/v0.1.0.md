Первый релиз Obsidian → Telegram Sync: перенос заметок из ZIP-архива
Obsidian в темы Telegram-супергруппы.

## Что умеет бот

- Создаёт темы по папкам vault и публикует заметки с форматированием.
- Превращает `[[wikilinks]]` в переходы между сообщениями.
- Обновляет изменённые заметки на месте при повторной загрузке.
- Поддерживает тему навигации с деревом файлов и картой связей.
- Позволяет вручную привязать существующие темы и сообщения бота.
- Ограничивает команды и загрузки списком Telegram ID.

## Начало работы

1. Установите Python 3.12 или новее и зависимости из `requirements.txt`.
2. Скопируйте `.env.example` в `.env`.
3. Укажите `BOT_TOKEN` и свой числовой ID в `ALLOWED_USER_IDS`.
4. Добавьте бота администратором в супергруппу с темами.
5. Запустите `python main.py`, отправьте `/setsupergroup` в группе и ZIP боту в личку.

Подробные команды для Windows, Linux / macOS и Render находятся в README
в исходниках этой версии. В разделе Assets доступны исходники проекта;
отдельный установщик не требуется.

## Ограничения версии

Разрешённые пользователи управляют одной общей группой. Отдельных хранилищ
для независимых пользователей нет.

Синхронизация запускается загрузкой ZIP или командой `/sync`;
автоматического наблюдения за локальным vault нет. Из архива обрабатываются
Markdown-файлы, вложения отдельно не загружаются.

SQLite нужно хранить постоянно. На Render ZIP и файл выбранной группы
пока находятся вне диска `/data`: после пересоздания контейнера может
потребоваться заново зарегистрировать группу и загрузить ZIP.
